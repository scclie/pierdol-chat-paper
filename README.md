# # pierdol-chat

minimal standalone chat plugin for papermc 26.3 and Java 25

- global chat as default
- `/local`: switch to local chat
- `/global`: switch back to global chat
- render `[G]` and `[L]` chat prefix
- radius 100 blocks
- world-coloured (over/nether/end) nicknames in chat and the tab list
- discordsrv /local filter
- configurable
